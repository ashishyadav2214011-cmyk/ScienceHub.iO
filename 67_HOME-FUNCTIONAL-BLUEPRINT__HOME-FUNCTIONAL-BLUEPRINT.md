# Home Functional Blueprint

Home is the command/overview layer. Major sections: Hero/Welcome; Academic Context; Today’s Overview; Today’s Focus; Continue Learning; Subject Hub; Study Pipeline; Practice Center; PYQ Center; Revision Center; Performance Snapshot; Learning Opportunities; Assets/Gallery; AI Ecosystem; Notifications/Events; User Control; Upgrade Guard; Offline/Online; System Status; Quick Actions; Footer/System Info.

Subjects: Physics, Chemistry, Biology, English, Hindi. PCB is a pathway identity, not a subject.

Learning hierarchy: Subject → Chapter → Topic → Concept → Practice → PYQ → Performance → Analysis → Revision → Mastery.

Home supports personalization, adaptive layout, customization, search, Sukoon.Brain, notifications, system/protection status, academic context, study overview/focus/continue, subject progress, pipeline, practice/PYQ/revision/performance/opportunities/assets/AI/offline/quick actions.

Opportunities include science, technology, biotech, genetics, AI, computers, academic opportunities, personal development, scholarships, competitions and relevant programs. Scholarship records retain source/provenance, eligibility, criteria, application period, deadline, status, verification state, documents and current source.

Home customization allows show/hide/reorder normal sections, saved layouts and AI suggestions. Mandatory safety/system/protection sections cannot be hidden.

Profile picture rule: user manually sets it; it cannot be replaced for 15 days after setting/changing. After 15 days the user may change it, restarting the 15-day period. AI, Upgrade Guard and system cannot silently replace it.
