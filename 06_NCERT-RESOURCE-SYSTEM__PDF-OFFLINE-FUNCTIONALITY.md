# PDF Offline Functionality

For legally obtained or officially available user resources:

Offline:
- open saved resources
- navigate pages
- search where technically supported
- map resources to academic items
- use saved learning/resource metadata

Online:
- check official/source updates
- detect newer editions/session resources
- refresh metadata
- prepare update
- request/execute user-approved update
- verify the resulting resource

Core functionality must not depend unnecessarily on continuous internet access.
