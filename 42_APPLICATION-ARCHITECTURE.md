# Application Architecture

ScienceHub.io is an offline-first student Study OS. Architecture is layered, contract-driven, permission-aware, and user-controlled.

Primary navigation: Home, Learning, Practice, Performance, Assets, Profile, Settings. Search and AI are global/system capabilities.

Control precedence: User → User Control → Upgrade Guard → System Architecture → AI Router → Specialized AI. This does not transfer final authority away from the user.
