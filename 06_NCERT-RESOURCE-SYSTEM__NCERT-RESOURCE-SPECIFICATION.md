# NCERT Resource Specification

ScienceHub supports an NCERT/textbook resource layer for Class 11 and Class 12.

Resource organization:
- Class
- Subject
- Book/resource
- Chapter
- Topic
- Language
- Edition/session
- Source/provenance

ScienceHub should support legally obtained or officially available PDFs/resources.

ScienceHub must not package or redistribute copyrighted NCERT books without appropriate rights.
