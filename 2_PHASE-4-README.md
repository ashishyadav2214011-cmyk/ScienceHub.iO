# ScienceHub.io — Phase 4 Core Application Foundation

This package provides the first runnable, dependency-light ScienceHub.io foundation for GitHub Pages/Codespaces.

Implemented foundation:
- 7 primary navigation items: Home, Learning, Practice, Performance, Assets, Profile, Settings
- Global Search entry
- Sukoon.Brain UI shell (floating, movable/minimizable shell; AI backend integration is not claimed complete)
- Local-first state using localStorage and IndexedDB
- Offline PWA foundation
- User-controlled layout preferences
- Profile picture 15-day change rule at the state layer
- Settings/permission control foundation
- Upgrade Guard status shell and activity-history foundation
- Basic recovery/error handling

Not claimed complete: full academic content engine, real AI models, psychology analysis, live World AI data, production authentication/backend, complete Upgrade Guard execution engine, full asset processing, and final release certification.
