# ScienceHub.io Identity

Primary academic context:
- Class 11 and Class 12
- PCB-focused organization
- Hindi and English
- UP Board context, with extensibility for user-selected boards/exams

Core flow:
Learn → Practice → Test → Analyse → Improve → Revise → Master

Personal-development direction:
Mindset → Behaviour → Communication → Responsibility → Personal Development
